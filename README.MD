# Менеджер паролей

Локальное консольное приложение на Python для хранения логинов и паролей. В меню можно добавлять, просматривать, редактировать и удалять записи, генерировать пароли и менять мастер-пароль.

## Установка и запуск

Понадобятся Python 3.14 или новее и [uv](https://docs.astral.sh/uv/getting-started/installation/). Выполните из корня проекта:

```sh
uv sync --locked
uv run --locked python main.py
```

Если в текущем каталоге есть `vault.dat`, приложение попросит мастер-пароль. Если файла нет, оно предложит создать хранилище и дважды ввести новый мастер-пароль длиной от восьми символов. При входе доступны три попытки за запуск. В списке записей пароли скрыты, а отдельный пункт меню показывает пароль выбранного сервиса.

## Структура

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа, вход в хранилище и обработчики меню |
| `console.py` | Консольный ввод и вывод, подтверждения и таблица записей |
| `vault.py` | Операции с записями и чтение и запись файла |
| `crypto_service.py` | Вывод ключа с PBKDF2-HMAC-SHA256 и шифрование Fernet |
| `expectetions.py` | Модель записи и исключения хранилища |
| `Generate_paasword.py` | Генерация паролей с помощью `secrets` |
| `tests/test_password_manager.py` | Тесты генератора и жизненного цикла хранилища |
| `pyproject.toml`, `uv.lock` | Настройки проекта и зафиксированные зависимости |

Первые 16 байт `vault.dat` содержат соль. За ней идёт токен Fernet с зашифрованным JSON. При смене мастер-пароля приложение генерирует новую соль и перешифровывает все записи. Файл перезаписывается целиком при каждом изменении.

## Проверки

```sh
uv run --locked pytest
uv run --locked ruff check .
uv run --locked ruff format --check .
```

Ruff проверяет импорты, типовые ошибки Python и форматирование. Pytest проверяет свойства сгенерированных паролей, сохранение и повторное открытие записей, ошибки операций и смену мастер-пароля. Для тестов создаются отдельные временные хранилища.
